### 5.5 配额管理接口

#### 5.5.1 创建配额

**接口**：`POST /api/v1/quotas`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| tenant_id | string | 否 | 租户ID |
| user_id | string | 否 | 用户ID |
| quota_type | string | 是 | 配额类型 |
| cpu_quota | float | 否 | CPU配额 |
| memory_quota_gb | float | 否 | 内存配额(GB) |
| gpu_quota | int | 否 | GPU配额 |
| gpu_hours_quota | float | 否 | GPU时长配额 |
| valid_from | datetime | 否 | 生效时间 |
| valid_until | datetime | 否 | 失效时间 |

**响应**：201 Created

```json
{
    "quota_id": "quota_001",
    "user_id": "user_001",
    "cpu_quota": 32,
    "memory_quota_gb": 128,
    "gpu_quota": 4,
    "gpu_hours_quota": 1000,
    "status": "active"
}
```

#### 5.5.2 获取当前用户配额使用情况

**接口**：`GET /api/v1/quotas/me/usage`

**响应**：200 OK

```json
{
    "user_id": "user_001",
    "cpu": {
        "quota": 32,
        "used": 16,
        "available": 16
    },
    "memory_gb": {
        "quota": 128,
        "used": 64,
        "available": 64
    },
    "gpu": {
        "quota": 4,
        "used": 2,
        "available": 2
    },
    "gpu_hours": {
        "quota": 1000,
        "used": 250.5,
        "available": 749.5
    }
}
```

### 5.8 错误码定义

#### 5.8.1 通用错误码

| 错误码 | HTTP状态码 | 说明 |
|--------|------------|------|
| UNAUTHORIZED | 401 | 未授权 |
| FORBIDDEN | 403 | 禁止访问 |
| NOT_FOUND | 404 | 资源不存在 |
| INTERNAL_ERROR | 500 | 内部错误 |

#### 5.8.2 业务错误码

| 错误码 | HTTP状态码 | 说明 |
|--------|------------|------|
| QUOTA_EXCEEDED | 403 | 配额超限 |
| RESOURCE_NOT_AVAILABLE | 503 | 资源不可用 |
| INVALID_TASK_STATE | 400 | 无效任务状态 |
| TASK_NOT_FOUND | 404 | 任务不存在 |
| NODE_NOT_FOUND | 404 | 节点不存在 |
| CLUSTER_NOT_FOUND | 404 | 集群不存在 |
| SCHEDULER_ERROR | 500 | 调度器错误 |

### 6.3 授权设计

#### 6.3.1 RBAC模型

系统采用基于角色的访问控制(RBAC)：

```
┌─────────┐     ┌─────────┐     ┌─────────┐
│  用户   │────▶│  角色   │────▶│  权限   │
│ (User)  │     │ (Role)  │     │(Permis- │
│         │     │         │     │  sion)  │
└─────────┘     └─────────┘     └─────────┘
```

#### 6.3.2 角色定义

| 角色 | 代码 | 权限范围 |
|------|------|----------|
| 系统管理员 | admin | 全部权限 |
| 租户管理员 | tenant_admin | 租户内全部权限 |
| 项目管理员 | project_admin | 项目内全部权限 |
| 普通用户 | user | 个人资源权限 |
| 只读用户 | viewer | 只读权限 |

#### 6.3.3 权限定义

| 资源 | 操作 | 权限代码 |
|------|------|----------|
| 集群 | 创建 | cluster:create |
| 集群 | 读取 | cluster:read |
| 集群 | 更新 | cluster:update |
| 集群 | 删除 | cluster:delete |
| 节点 | 管理 | node:manage |
| 任务 | 创建 | task:create |
| 任务 | 读取 | task:read |
| 任务 | 取消 | task:cancel |
| 配额 | 管理 | quota:manage |

### 8.6 常见问题

#### Q1: 任务一直处于pending状态？

**可能原因**：
- 资源配额不足
- 没有满足要求的节点
- 调度器繁忙

**解决方案**：
1. 检查配额使用情况
2. 减少资源请求
3. 等待资源释放

#### Q2: 任务执行失败？

**排查步骤**：
1. 查看任务日志
2. 检查容器镜像是否正确
3. 验证命令参数
4. 确认资源是否充足

#### Q3: 如何提高任务优先级？

**操作方法**：
1. 在任务列表找到目标任务
2. 点击"调整优先级"
3. 设置新的优先级值(-100到100)
